# Excel version

Open `Forwards_Market_Making_Simulator.xlsx` (Excel 2016+ or LibreOffice). No macros, no add-ins; all logic is live formulas.

1. **Guide** – overview of the sheets.
2. **Inputs** – change blue-on-yellow cells: rates, tenor, clip size, spread, skew, limits, hedge cost.
3. **Simulation** – edit the blue columns *spot shock (ticks)* and *client action (BUY/SELL/NONE)* to run your own scenario.
4. **Summary** – activity, P&L attribution, limit usage and charts. **Pricing** has a quote calculator and skew ladder.
